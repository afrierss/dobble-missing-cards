# dobble-missing-cards
Dobble besteht eigentlich aus 57 Karten. Die herkömmlichen im Handel erhältlichen Spiele bestehen nur aus 55 Karten. Wie müssen nun die zwei fehlenden Karten aufgebaut sein?

Meine Ausgangstabellen:

"Symbole"
(SymbolID | Symbolname)

"Match"
(Kartennummer | Symbolname)

Diese Tabellen habe ich manuell erarbeitet und in Excel eingegeben.
